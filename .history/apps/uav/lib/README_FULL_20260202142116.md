# UAV Shared Libraries - Thư Viện Dùng Chung

## 📋 Tổng Quan

Thư mục `lib/` chứa tất cả các **thư viện thuần algorithm** và **utilities** được dùng chung giữa các ứng dụng UAV. Đặc điểm chính:

1. **Không phụ thuộc hardware:** Pure C/C++ algorithms
2. **Reusable:** Có thể dùng trong bất kỳ app nào
3. **Testable:** Có thể test độc lập trên PC
4. **No dynamic allocation:** Phù hợp realtime systems

## 📐 mathlib/ - Thư Viện Toán Học

### Mục Đích

Cung cấp các **data types** và **operations** toán học cơ bản cho UAV:
- Vector 3D (vị trí, vận tốc, gia tốc)
- Matrix 3×3 (rotation, transformation)
- Quaternion (attitude representation)
- Các hằng số và utility functions

### Files

| File | Nội Dung |
|------|----------|
| `mathlib.hpp` | Master include, constants, utilities |
| `vector3.hpp` | Vector 3D class với operators |
| `matrix3.hpp` | Matrix 3×3 class |
| `quaternion.hpp` | Quaternion class |
| `filters.hpp` | Simple IIR filters |

### Ví Dụ Sử Dụng

```cpp
#include <uav/lib/mathlib/mathlib.hpp>

using namespace mathlib;

// Vector operations
Vector3f pos(1.0f, 2.0f, 3.0f);
Vector3f vel = pos * 2.0f;
float distance = pos.length();

// Quaternion
Quaternionf q = Quaternionf::from_euler(roll, pitch, yaw);
Vector3f body_accel = q.rotate(world_accel);

// Constants
float g = GRAVITY_MSS;  // 9.80665 m/s²
float deg = 45.0f * DEG_TO_RAD;  // → radians
```

## 🔊 dsp/ - Xử Lý Tín Hiệu Số

### Mục Đích

Các **digital filters** để xử lý tín hiệu từ sensors:
- **Lowpass:** Loại bỏ nhiễu cao tần
- **Notch:** Loại bỏ frequency cụ thể (motor vibration)
- **Median:** Loại bỏ spikes

### LowPassFilter2p

Biquad lowpass filter (2nd order Butterworth):

```cpp
#include <uav/lib/dsp/filters.hpp>

using namespace uav::dsp;

LowPassFilter2p gyro_filter;
gyro_filter.set_cutoff_frequency(1000.0f, 100.0f);  // fs=1kHz, fc=100Hz

// Trong loop
float filtered_gyro = gyro_filter.apply(raw_gyro);
```

### NotchFilter

Loại bỏ frequency từ motor:

```cpp
NotchFilter notch;
notch.set_notch(1000.0f, 400.0f, 0.5f);  // fs=1kHz, f_notch=400Hz, Q=0.5

float clean_accel = notch.apply(vibrating_accel);
```

### MedianFilter

Robust với outliers:

```cpp
MedianFilter<5> median;  // Window size 5

// Loại bỏ spike
float clean = median.apply(noisy_value);
```

## 🔀 sensor_processing/ - IMU Fusion

### Mục Đích

Kết hợp dữ liệu từ **4 IMU** để:
- Tăng **accuracy** bằng averaging
- Tăng **reliability** bằng redundancy
- **Detect** và loại trừ IMU lỗi

### Chế Độ Fusion

| Mode | Mô Tả | Use Case |
|------|-------|----------|
| `VOTING` | Median voting | Mặc định, robust với 1 sensor lỗi |
| `WEIGHTED` | Weighted average theo noise | Khi biết chất lượng từng sensor |
| `PRIMARY` | Dùng IMU chính + fallback | Latency thấp nhất |

### API

```cpp
#include <uav/lib/sensor_processing/imu_fusion.hpp>

using namespace uav::sensor_processing;

ImuFusion fusion;
fusion.set_mode(FusionMode::VOTING);

// Cập nhật từng IMU
fusion.update(0, imu0_data);
fusion.update(1, imu1_data);
fusion.update(2, imu2_data);
fusion.update(3, imu3_data);

// Lấy kết quả fusion
FusedImuData result;
if (fusion.get_fused_data(&result)) {
    // result.gyro[3], result.accel[3]
}

// Kiểm tra healthy IMUs
uint8_t healthy = fusion.get_healthy_imus();  // Bitmask
```

### Fault Detection

```cpp
// IMU được coi là faulty khi:
// - Deviation từ median > threshold
// - Liên tiếp > 10 samples

// Threshold mặc định:
// Gyro: 0.1 rad/s
// Accel: 2.0 m/s²
```

## 📏 calibration/ - Calibration

### Mục Đích

Áp dụng **calibration corrections** cho sensor data:
- **Bias:** Offset khi đứng yên
- **Scale:** Hệ số tỷ lệ
- **Rotation:** Board orientation

### Calibration Model

```
calibrated = rotation × ((raw - bias) * scale)
```

### API

```cpp
#include <uav/lib/calibration/sensor_calibration.hpp>

using namespace calibration;

SensorCalibration cal;

// Load calibration data
cal.set_bias(Vector3f(-0.01f, 0.02f, -0.005f));
cal.set_scale(Vector3f(1.001f, 0.999f, 1.002f));
cal.set_rotation(Dcmf::from_euler(0, 0, M_PI));  // 180° yaw

// Apply calibration
Vector3f raw_gyro(gyro_x, gyro_y, gyro_z);
Vector3f calibrated = cal.apply(raw_gyro);
```

## ❤️ health/ - Health Monitor

### Mục Đích

Giám sát **sức khỏe hệ thống**:
- Detect component failures
- Track heartbeats
- Trigger failsafe khi cần

### Health Levels

| Level | Mô Tả | Action |
|-------|-------|--------|
| `NOMINAL` | Tất cả OK | Normal operation |
| `DEGRADED` | Một số redundancy mất | Warning, continue |
| `CRITICAL` | Minimum function | Land soon |
| `FAILSAFE` | Emergency | Hold attitude only |

### API

```cpp
#include <uav/lib/health/health_monitor.hpp>

using namespace uav::health;

HealthMonitor monitor;
monitor.init();

// Components gọi heartbeat
monitor.heartbeat(ComponentId::IMU_0);
monitor.heartbeat(ComponentId::EKF);

// Main loop check
HealthLevel level = monitor.get_system_level();
if (level == HealthLevel::CRITICAL) {
    trigger_land();
}
```

## ⏱️ platform/ - Platform Abstraction

### hrt.h - High Resolution Timer

```c
#include <uav/lib/platform/hrt.h>

// Lấy timestamp microseconds
uint64_t now = hrt_absolute_time();

// Sleep chính xác
hrt_usleep(1000);  // 1 ms
```

### timebase.h - Master Timebase

Cung cấp **multi-rate scheduling**:

```c
#include <uav/lib/platform/timebase.h>

// Init một lần
timebase_init();

// Task đợi domain của mình
while (!should_exit) {
    timebase_wait_domain(DOMAIN_MEDIUM);  // 1 kHz
    
    // Do work...
}
```

| Domain | Rate | Use |
|--------|------|-----|
| `DOMAIN_FAST` | 8 kHz | IMU acquisition |
| `DOMAIN_MEDIUM` | 1 kHz | EKF predict |
| `DOMAIN_SLOW` | 100 Hz | Baro, Mag, GPS |
| `DOMAIN_ASYNC` | Event | Telemetry, logging |

## 🛠️ utils/ - Tiện Ích

### RingBuffer

Lock-free SPSC ring buffer:

```cpp
#include <uav/lib/utils/ringbuf.hpp>

using namespace uav::utils;

RingBuffer<sensor_imu_s, 16> imu_ring;

// Producer (ISR/DMA)
imu_ring.push(sample);

// Consumer (processing task)
sensor_imu_s samples[8];
int count = imu_ring.pop_batch(samples, 8);
```

### Critical Sections

```cpp
#include <uav/lib/utils/critical.hpp>

// Disable interrupts briefly
{
    CriticalSection cs;
    // Atomic operations here
}  // Re-enable on destructor
```

### DMA Double Buffer

```cpp
#include <uav/lib/utils/dma_buffer.hpp>

DmaDoubleBuffer<sensor_imu_s> dma_buf;

// DMA writes to back buffer
dma_buf.get_dma_target();

// Swap when DMA complete
dma_buf.swap();

// Read from front buffer
sensor_imu_s* data = dma_buf.get_read_buffer();
```

## 📝 Best Practices

### 1. Include Paths

```cpp
// Dùng full path từ uav/
#include <uav/lib/mathlib/mathlib.hpp>
#include <uav/lib/dsp/filters.hpp>
```

### 2. Namespaces

```cpp
// Mỗi library có namespace riêng
using namespace mathlib;
using namespace uav::dsp;
using namespace uav::sensor_processing;
```

### 3. No Dynamic Allocation

```cpp
// ❌ Không dùng trong realtime code
auto* buffer = new float[100];

// ✅ Static allocation
static float buffer[100];
```
