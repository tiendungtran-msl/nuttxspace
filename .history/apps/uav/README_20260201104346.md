# UAV Avionics Stack trên NuttX

## Tổng Quan

Đây là hệ thống phần mềm điều khiển UAV được thiết kế theo kiến trúc **multi-app**
tham chiếu từ PX4 Autopilot, nhưng được viết lại hoàn toàn cho NuttX RTOS.

### Triết Lý Thiết Kế

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                    NGUYÊN TẮC THIẾT KẾ FLIGHT-CRITICAL                      │
├─────────────────────────────────────────────────────────────────────────────┤
│ 1. FAULT ISOLATION    : Mỗi app là task riêng, crash 1 không kill system   │
│ 2. DETERMINISM        : Timing có thể dự đoán, không jitter > 50µs         │
│ 3. NO DYNAMIC ALLOC   : Không malloc/new trong loop realtime               │
│ 4. LOOSE COUPLING     : Giao tiếp chỉ qua uORB, không gọi hàm trực tiếp    │
│ 5. SINGLE OWNERSHIP   : Mỗi hardware chỉ có 1 owner duy nhất               │
└─────────────────────────────────────────────────────────────────────────────┘
```

## Bảng Phân Chia App

| App | Priority | Rate | Stack | Nhiệm vụ | Publishes | Subscribes |
|-----|----------|------|-------|----------|-----------|------------|
| sensors_app | 250 | 1kHz | 4KB | Driver polling | sensor_imu, sensor_mag, sensor_baro | - |
| estimator_app | 240 | 250Hz | 8KB | EKF2 fusion | vehicle_attitude, vehicle_local_position | sensor_* |
| state_app | 220 | 50Hz | 4KB | Health monitor | vehicle_state | vehicle_*, ekf2_status |

## Thứ Tự Khởi Động

```bash
nsh> sensors start        # Khởi động trước (cung cấp dữ liệu)
nsh> estimator start      # Phụ thuộc sensors
nsh> state start          # Phụ thuộc estimator
```

## Ràng Buộc Kỹ Thuật

1. **Không dynamic allocation trong loop**: Tất cả buffer phải static
2. **HRT cho timing**: Dùng `hrt_absolute_time()`, không dùng `clock_gettime()`
3. **Không gọi chéo module**: Chỉ giao tiếp qua uORB topics
4. **Single SPI owner**: Chỉ sensors_app được truy cập SPI
5. **FIFO scheduling**: Dùng `SCHED_FIFO` cho realtime tasks

## Hardware Target

- MCU: STM32H743 (Cortex-M7 @ 480MHz)
- IMU: ICM-42688-P x4 (SPI1)
- Mag: BMM150 (I2C1) - planned
- Baro: MS5611 (I2C1) - planned
- GPS: u-blox (UART) - planned

## Build Instructions

```bash
# Trong NuttX root
cd nuttx
make menuconfig
# Enable: Application Configuration -> UAV -> [*] All apps

make -j$(nproc)
```
